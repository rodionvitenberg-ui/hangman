## Функционал приложения и меню консольного интерфейса

Главное меню при старте — приложение предлагает начать новую партию (1) или выйти из программы (2).

Генерация слова - при старте раунда из словаря случайным образом выбирается слово длиной от 6 символов.

Игровой процесс - после каждой введённой буквы консоль обновляет стадию виселицы, маску слова с открытыми буквами, статус хода и счётчик оставшихся попыток (всего даётся 6 прав на ошибку).

Валидация ввода - повторно введённые буквы, пустой ввод, несколько символов подряд или не-буквы отклоняются без списания попыток.

Завершение раунда - при отгадывании всех букв или исчерпании попыток выводится итоговый результат (победа или поражение с раскрытием загаданного слова), после чего по нажатию Enter игра возвращается в главное меню.
